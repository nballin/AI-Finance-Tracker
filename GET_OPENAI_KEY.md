# How to Get OpenAI API Key - Step by Step Guide

## Step 1: Go to OpenAI Platform
Visit: https://platform.openai.com/api-keys

(I've opened this in your browser)

## Step 2: Sign Up or Log In
- If you don't have an account: Click "Sign up" and create an account
- If you have an account: Click "Log in"

## Step 3: Add Payment Method (Required)
- OpenAI requires a payment method to use the API
- Go to: https://platform.openai.com/account/billing
- Click "Add payment method"
- Add a credit card (they charge per use, very affordable)

## Step 4: Create API Key
1. Go back to: https://platform.openai.com/api-keys
2. Click the **"+ Create new secret key"** button
3. Give it a name (e.g., "Finance Tracker")
4. Click **"Create secret key"**
5. **IMPORTANT**: Copy the key immediately - you'll only see it once!
   - It will look like: `sk-proj-...` or `sk-...`
   - Save it somewhere safe

## Step 5: Add to Your Project
Once you have the key, come back here and paste it, and I'll add it to your project!

## Cost Information
- **Very affordable**: GPT-3.5-turbo costs ~$0.002 per 1K tokens
- **Typical query**: Less than $0.01 per conversation
- **Free tier**: $5 free credit when you sign up
- **Set limits**: You can set spending limits in your account

## Security Notes
- Never share your API key publicly
- Don't commit it to git (it's already in .gitignore)
- You can revoke keys anytime from the OpenAI dashboard

## Troubleshooting
- **"Insufficient credits"**: Add payment method
- **"Invalid API key"**: Make sure you copied the full key
- **"Rate limit"**: You're making too many requests (unlikely for personal use)
